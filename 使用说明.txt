爱呵呵 · 听记 v0.2.3
开发者：爱呵呵

1. 双击「爱呵呵听记.exe」或桌面快捷方式。
2. 点击右上角「API 设置」，填写语音接口地址、模型名称、API Key。
3. 需要知识整理时，再填写文本模型接口；否则取消勾选「同时生成 AI 知识文档」。
4. 点击选择视频或音频，开始处理。
5. 完成后选择导出格式，点击「导出文档」，在系统窗口选择保存位置。

支持：完整转写稿、AI 知识文档、Markdown、TXT、JSON；长音频分段；失败后继续。
暂不支持：识别视频中的 PPT / 代码 / 画面文字、Word 导出、批量任务。
API Key 仅用于当前运行页面，不存盘；关闭软件后需要重新填写。
语音和文本 API 可以使用不同服务商，调用费用由服务商收取。
只兼容聊天的 API 不一定支持语音转写。

窗口操作：
左上角红色：退出；黄色：最小化；绿色：最大化。
拖动标题栏可移动窗口，拖动右下角可调整大小。
Ctrl+O 选择文件，Ctrl+, 打开设置。
右下角「打开文件夹」可找到全部本地文档。

使用环境：
Windows 10 / 11，Microsoft Edge WebView2 Runtime。
不需要 Rust、Python、Node 或本地模型。FFmpeg 随 tools 文件夹附带。
移动软件时请连同 tools 文件夹一起移动。

转写和整理结果可能有错误，请对照原音频核对。
